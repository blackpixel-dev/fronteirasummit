# Fronteira Summit — Landing page

Protótipo responsivo em HTML, CSS e JavaScript puro.

## Como visualizar
Abra `index.html` em um navegador ou publique a pasta em um serviço de hospedagem estática.

## Antes de publicar
- Substituir a marca tipográfica provisória pela logo oficial fornecida pela organização.
- Confirmar datas, horários, local, programação e canais oficiais.
- Conectar o formulário a uma plataforma real de inscrição/CRM (atualmente ele apenas valida os campos no navegador).
- Adicionar política de privacidade e definir a finalidade/base legal para tratamento dos dados.
- Testar a integração, os links oficiais, acessibilidade e comportamento em dispositivos reais.

Nenhum depoimento, número de público, data ou resultado não confirmado foi inventado.
